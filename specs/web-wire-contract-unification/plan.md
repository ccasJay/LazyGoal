# Web 传输契约统一执行计划

依据已批准的 [Spec](./spec.md) 实现。实现顺序：TODO 1 扩展 Contract AST；TODO 2 建立共享合同、JSON 基础与早期定义检查；TODO 3（会话/Run/Plan）与 TODO 4（Interaction/Action Review/输入状态）在共享合同就绪后可并行；TODO 5（Activity/SSE）依赖 TODO 4 的会话状态合同；TODO 6（Trajectory/Model Input/Metrics）与 TODO 7（Provider/Model/命令结果）可并行；TODO 8（会话/创建/Plan/Action Review 入站 parser）与 TODO 9（Provider/Model/权限/授权/归档入站 parser）分别依赖相应命令合同；TODO 10 最后清理平行字段表、更新文档并完成 Bundle/依赖审计。每个 TODO 只做轻量基本验证，完整回归留到 Feature Verification。

本计划只修改 Contract AST 新节点、`packages/web-contracts`、`packages/browser` 入站 parser、相关测试与模块文档；当前工作树中 runtime、model-context、goal-board 等无关未提交修改不纳入实现、验证或提交。

测试更新只允许反映 Spec 明确列出的行为变化：声明字段完整校验、严格枚举、可选字段显式 `undefined` 拒绝、`scope` 默认移除、`apiKey:null`/`scope:null` 拒绝、`isJsonValue` 拒绝非普通对象。不得为通过而删除或放宽其他断言。
