# 轨迹看板交互修复 需求

## 引言

本需求旨在修复 LazyGoal 浏览器轨迹看板（Trajectory Board）及交互原型在事件连续审查、时间轴联动、步骤折叠、无障碍可访问性与视图呈现上的关键体验缺陷，提升轨迹排查与模型调用复盘的流畅度与合规性。范围覆盖检查器 Tab 记忆、泳道筛选联动、步骤折叠状态保持、A11y 焦点与属性规范化、剪贴板异常保护及时间轴滚轮解耦，不涉及底层数据格式与运行时领域状态变更。

## 需求

### 需求 1：详情面板 Tab 状态记忆与优雅回退

**用户故事：** 作为开发者或审计员，我希望在点击上一个/下一个事件箭头连续浏览轨迹时保持当前选中的选项卡，以便高效比对不同事件的执行结果或原始载荷，而无需重复手动点击切换。

#### 验收标准

1. <a id="req-1-1"></a> 当用户使用详情面板顶部的切换按钮导航至相邻事件时，如果目标事件包含当前活动选项卡所对应的数据载荷，系统必须保留当前选中的选项卡。
2. <a id="req-1-2"></a> 当用户导航至不包含当前活动选项卡数据的新事件（例如当前处于 Input 或 Result 标签页但新事件无对应载荷）时，系统必须优雅回退至 Summary 选项卡。
3. <a id="req-1-3"></a> 当用户通过列表行直接点击选择任意事件时，系统必须默认展示 Summary 选项卡。

### 需求 2：时间轴泳道与检索筛选状态联动及非破坏性定位

**用户故事：** 作为审查人员，我希望时间轴泳道刻度能够实时反映当前的搜索与分类结果，并在点击刻度时保持检索条件，以便直观感知匹配事件的时序分布而不丢失过滤上下文。

#### 验收标准

1. <a id="req-2-1"></a> 当搜索框存在过滤文本或用户选择了特定事件分类时，时间轴泳道中未命中当前筛选条件的刻度必须以半透明弱化样式呈现，仅高亮命中事件。
2. <a id="req-2-2"></a> 当用户点击时间轴上任意事件刻度（包括弱化刻度）时，系统必须定位并选中该事件，同时必须完整保留当前的搜索输入与分类选择，严禁静默清空筛选条件。
3. <a id="req-2-3"></a> 当选中的刻度位于当前搜索结果之外时，系统必须提供明确的可视状态提示，指示该事件属于全量时间线但未命中当前过滤条件。

### 需求 3：步骤折叠稳定性与精确引导文案

**用户故事：** 作为开发者，我希望在收起步骤分组时避免当前选中的事件发生非预期跳变，并在全部折叠时获得清晰的操作指引，以便准确控制长会话轨迹的视区密度。

#### 验收标准

1. <a id="req-3-1"></a> 当用户折叠包含当前选中事件的步骤时，系统必须保持该事件的选中与审查状态，不得自动跳转至其他步骤的可见事件。
2. <a id="req-3-2"></a> 当列表所有步骤均被折叠且没有展开的事件行时，详情检查器必须明确提示“所有步骤已收起，请展开步骤以查看事件”，不得显示要求用户更改搜索词或分类的误导性提示。
3. <a id="req-3-3"></a> 当应用筛选条件导致匹配事件所属步骤原本处于折叠状态时，系统必须仅展开包含匹配项的分组，不应盲目重置其他无关步骤的折叠偏好。

### 需求 4：无障碍合规、焦点保持与复制异常保护

**用户故事：** 作为键盘操作者与开发者，我希望事件列表操作不打断键盘焦点链条，且复制事件数据时具备可靠的错误反馈，以便获得稳定无障碍的操作体验。

#### 验收标准

1. <a id="req-4-1"></a> 当用户在事件列表中使用键盘或鼠标切换选中项时，系统必须确保键盘焦点稳定停留在当前选中行或目标交互区域，不得将焦点重置到页面顶层主体。
2. <a id="req-4-2"></a> 事件列表行元素必须遵循标准可访问性语义，系统必须移除原生按钮上的非法 aria-selected 属性，采用合规的列表或网格角色定义。
3. <a id="req-4-3"></a> 当用户点击复制事件 JSON 按钮时，系统必须捕获可能的权限拒绝或上下文异常；如果复制失败，必须呈现明确的失败反馈，不得抛出未捕获的运行时异常。

### 需求 5：检查器纯净视图收敛与时间轴滚轮解耦

**用户故事：** 作为复盘分析人员，我希望检查器的数据标签页保持纯粹，且页面垂直滚动不被时间轴无意阻断，以便专注查看纯净内容并顺畅浏览页面。

#### 验收标准

1. <a id="req-5-1"></a> 在详情检查器中，执行关系说明卡片（如 Program 调用关系）必须仅在 Summary 或关系专属视图中呈现，切换至 Raw、Input 或 Result 等数据视图时不得追加干扰内容。
2. <a id="req-5-2"></a> 当光标置于时间轴区域且用户执行垂直滚动时，系统必须允许页面正常纵向滚动，仅在配合修饰键（如 Shift 或 Ctrl/Cmd）或进入明确的缩放模式时才拦截滚轮进行时间轴缩放。

## 风险与待确认

- 风险等级：low；理由：改动仅涉及前端交互逻辑、视觉弱化样式与无障碍语义修正，完全在前端组件内部闭环，不改动公共契约、网络接口或持久化状态，具有极高的可逆性。
- 关键操作：无
- 风险：无
- 待确认：无
