# LazyGoal

LazyGoal 是 Goal 驱动、可恢复的 Agent Runtime。使用 `node bin/lazygoal.cjs web` 启动本机服务；评测命令从 `node bin/lazygoal.cjs eval` 进入。依赖与常用脚本见 [package.json](./package.json)。
